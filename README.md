# Certified Counterfactual Explainability of Multi-Objective Decisions

Code, tests, and archived outputs for the study **Certified Counterfactual Explainability of Multi-Objective Decisions under Preference Uncertainty and Finite-Support Wasserstein Distributional Ambiguity**.

The study asks when a designated alternative can be certified as optimal against every competitor under every admissible preference (a polyhedral perturbation set) and every scenario distribution in a finite-support Wasserstein ball, and how far the preference uncertainty can grow before this certificate fails. The code implements

- the minimum-change (L1) preference explanation, solved by LP separation over transport plans;
- the fixed-center preference-stability radius, computed directly as a minimum of linear-fractional transport thresholds that a Charnes–Cooper transformation turns into linear programs;
- an independent bisection routine and a vertex-and-transport separation audit used as cross-checks.

## Installation and tests

Python 3.11 or newer is required.

```bash
python -m pip install -r requirements.txt
python -m pytest Implementation/tests -q
```

Linear programs are solved with the HiGHS solver bundled with SciPy.

## Reproducing the reported results

Commands are run from `Implementation/`. For the 60-instance benchmark, for example:

```bash
cd Implementation
PYTHONPATH=src python src/evaluation/final_v6_experiment.py ../Experiments/results/final_v6_60cases.json
python scripts/operational_validation_v12.py
```

Re-running these two commands reproduces the archived counts, objective values, and stability radii; only the timing columns vary between machines.

Main outcome of the WDBC study (569 observations, five stratified folds as scenarios): one policy (referral threshold 0.30) is uniformly valid at ambiguity radii 0, 0.0001, and 0.001, with preference-stability radii 0.896, 0.857, and 0.489; no policy is uniformly valid at radii 0.003 and 0.01. Mean cross-validation ROC AUC is 0.9950.

The remaining files in `Experiments/results/` (`v3_benchmark.json`, `benchmark_v4.json`, `benchmark_v5*.{json,csv}`, `wasserstein_v2.json`, `wine_v6.json`, `stability_v8.json`, `radius_benchmark_v9.json`) are development outputs for earlier or more conservative certificate variants and are not part of the reported tables.

Timing values are local wall-clock observations on a single machine and are not hardware-normalized.

## Scope and interpretation

- Uniform validity is stronger than minimax optimality; certification can fail even when minimax-optimal alternatives exist.
- The LP certificates are numerical and subject to solver tolerances; they are not exact-arithmetic proofs.
- Ties are accepted (weak optimality). The stability radius is defined for a fixed preference center and target; joint optimization of center and radius is not addressed.
- The WDBC study is retrospective and semi-synthetic. Observations are real, but policies, preference weights, uncertainty radii, and transport costs are specified by the author and are not clinically calibrated. The study is not a clinical validation or a medical recommendation.
- The Charnes–Cooper transformation, vertex reduction, and Wasserstein transport linear programs are classical tools; the contribution lies in their combination into a certificate with a precisely stated meaning.

## Data

The WDBC data are distributed with scikit-learn (`sklearn.datasets.load_breast_cancer`) and the UCI Machine Learning Repository (https://doi.org/10.24432/C5DW2B). No new data were collected and no protected health information is included.
